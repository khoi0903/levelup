Cách chia collection

Nguyên tắc MongoDB: dữ liệu nhỏ, có giới hạn, luôn đọc cùng nhau thì nhúng vào một document. Dữ liệu tăng mãi theo thời gian thì tách collection riêng. Nhờ vậy 51 bảng Postgres gọn lại còn 22 collection.

Ảnh hưởng tới kế hoạch 10 tuần

Chọn MongoDB thì không dùng được Supabase (Supabase chỉ có Postgres). Team phải tự viết thêm lớp API mà trước đó Supabase làm sẵn: đăng nhập, phân quyền, upload ảnh, job hẹn giờ. Ước tính backend mất thêm khoảng 1,5–2 tuần. Với 10 tuần, nên có 2 người làm backend, hoặc một Flutter dev hỗ trợ viết API ở S1 và S2.
  • Nên chọn MongoDB nếu team đã quen MongoDB và Node.js. Khi đó tốc độ làm quen quan trọng hơn phần Supabase làm sẵn.
  • Nên giữ Postgres + Supabase nếu team chưa quen cả hai, vì Supabase tiết kiệm được lớp API cho lịch 10 tuần.

Script tạo database

Chạy bằng mongosh "<connection string>/fitness" init.js. Chạy lại nhiều lần vẫn an toàn: collection đã có thì chỉ cập nhật validator.

mongo/init.js 
// =====================================================================
// Fitness app MVP · MongoDB schema
// Chạy: mongosh "<connection string>/fitness" init.js
// Yêu cầu: MongoDB 7+ chạy dạng replica set (Atlas mặc định 3 node)
//          để có transaction và change stream.
// Quy ước: _id là ObjectId; thời điểm là Date (UTC);
//          "ngày" của người dùng lưu chuỗi "YYYY-MM-DD" ở localDate;
//          tuần bắt đầu Thứ Hai, lưu ở weekStart "YYYY-MM-DD".
// =====================================================================

const dbx = db.getSiblingDB("fitness");

// Tạo collection kèm validator. Chạy lại nhiều lần vẫn an toàn.
function coll(name, schema, opts = {}) {
  const exists = dbx.getCollectionNames().includes(name);
  if (!exists) {
    dbx.createCollection(name, { ...(schema ? { validator: { $jsonSchema: schema } } : {}), ...opts });
  } else if (schema) {
    dbx.runCommand({ collMod: name, validator: { $jsonSchema: schema } });
  }
  return dbx.getCollection(name);
}

const VARIANT = { enum: ["normal", "light", "quick5", "advanced"] };
