Bỏ buổi và nhắc quay lại

sequenceDiagram
  participant S as Cloud Scheduler
  participant API as API
  participant DB as MongoDB
  participant AI as Claude API
  participant FCM as Firebase Messaging
  participant App as App Flutter
  S->>API: POST /jobs/tick (00:05 giờ người dùng)
  API->>DB: Buổi hôm qua còn planned và chưa có log
  API->>DB: sessions.$.status skipped
  API->>DB: users.reengagement: consecutiveMissed + 1, đổi stage
  alt Stage missed_2
    API->>AI: Viết tin hỏi lý do theo phong cách, nhắc motivationText
    API->>DB: insert coach_messages (thẻ 5 lựa chọn lý do)
    API->>FCM: Push qua cổng gửi thông báo
    FCM-->>App: Thông báo
    App->>API: POST /skip-reports (reason busy)
    API->>DB: insert skip_reports
    API->>DB: training_plans: buổi tối nay thành 10 phút, dời buổi sau
    API-->>App: Tin coach + thẻ Đồng ý, Chọn giờ khác, Nghỉ hôm nay
  else Stage lapsed_7 hoặc lapsed_14
    API->>DB: Tạo tuần khởi động lại nhẹ hơn
    API->>FCM: Tin quay lại (lapsed_14: mỗi tuần 1 tin, tối đa 2)
  end
Lý doAPI làm gì
busyRút buổi còn 10 phút, dời buổi kế tiếp sang ngày trống
tiredGiảm cường độ các buổi còn lại trong tuần
painThêm vào users.injuries, thay bài bằng bài an toàn, khuyên đi khám nếu kéo dài
boredĐổi sang template khác cùng mục tiêu
forgotĐề xuất đổi giờ nhắc trong notificationSettings

Lỗi và mất mạng

Tình huốngXử lý
Mất mạng khi đang tậpApp lưu buổi tập vào SQLite, gửi lại khi có mạng. clientId giúp API không lưu trùng
Claude chậm hoặc lỗiHết 20 giây thì báo "Coach đang bận, thử lại nhé", thử lại 1 lần. Không bao giờ chặn việc lưu buổi tập vì AI lỗi
AI trả JSON sai định dạngKiểm tra bằng schema. Sai thì hỏi lại 1 lần, vẫn sai thì dùng luật cố định
Job chạy trùng hoặc chạy lạiMọi thao tác của job đều có thể chạy lại an toàn: kiểm tra trạng thái trước khi đổi, thông báo có dedupeKey
Token FCM hết hạnXóa token khỏi users.devices, app gửi token mới khi mở lại
MongoDB đổi node primaryDriver tự kết nối lại. Bật retryWrites để lệnh ghi tự chạy lại
Luồng backend cho bản demo 10 tuần. Database và script tạo collection ở trang Backend MongoDB App Fitness.
